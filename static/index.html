How It Works

🧠

CNN Architecture

A 3-block convolutional network trained on CIFAR-10 (10 classes). Achieves ~85%+ accuracy on the 10,000-image test set.

⚡

Fault Injection

Selected percentages of model weights are set to zero, simulating hardware memory failures or bit-flip errors in edge AI chips.

🔍

Fault Detection

Gradient-based analysis identifies which weights have negligible contribution (low gradient magnitude) — the signature of injected faults.

🩺

7 Healing Methods

From gradient re-initialisation to autoencoder reconstruction and neuron regrowth — multiple strategies target faults at different severities.
